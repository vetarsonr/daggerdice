# DaggerDice IT

Estensione per [Owlbear Rodeo](https://www.owlbear.rodeo/) che permette di tirare dadi di Daggerheart in 3D senza account o servizi esterni. 
Funziona anche per giocatori ospiti: il GM attiva l'estensione nella stanza e i tiri pubblici vengono ricevuti da tutti, anche quando il pannello del giocatore è chiuso.
